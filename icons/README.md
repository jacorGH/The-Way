# The Way — App Icons

Icon assets for the iOS and Android app **The Way**.

## Included
- `apple-touch-icon.png` — 180 × 180 (iOS Home Screen)
- `favicon-32.png` — 32 × 32
- `icon-192.png` — 192 × 192 (Android/PWA)
- `icon-512.png` — 512 × 512 (Android/PWA)
- `icon-1024.png` — 1024 × 1024 master
- `icon.svg` — self-contained SVG wrapper containing the 1024 px artwork

## Notes
- All PNGs are square, optimized, and exported from the same 1024 × 1024 master.
- The SVG is an embedded-raster wrapper, not a fully vector redraw.
- For Android adaptive icons, a separate foreground/background layer may be preferable if you later want the launcher to apply its own mask.
